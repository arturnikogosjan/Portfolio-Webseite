# Portfolio-Webseite – Artur Nikogosjan

## Über das Projekt

Ich habe diese Portfolio-Webseite erstellt, um mich selbst und meine bisherigen Projekte vorzustellen. Sie soll meine ersten Schritte in der Webentwicklung zeigen und mir dabei helfen, praktische Erfahrungen im Programmieren zu sammeln.

Die Webseite habe ich mithilfe eines YouTube-Tutorials umgesetzt.

## Live-Demo

[Portfolio-Webseite ansehen](https://portfolioarturnikogosjan.netlify.app)

## Verwendete Technologien

- HTML
- CSS
- Javascripz

## Ziel des Projekts

- Meine bisherigen Projekte präsentieren
- Erste praktische Erfahrungen in der Webentwicklung sammeln
- Den Aufbau und die Gestaltung von Webseiten besser verstehen
- Meine Projekte im Rahmen meiner Bewerbung um eine Ausbildung zum Fachinformatiker für Anwendungsentwicklung zeigen
